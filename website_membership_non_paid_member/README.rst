This modules extends the online members directory for displaying members
that are invoiced, but have non paid membership.

It so allows to display all members, even if the member did'nt paid yet
his membership, or if the accountant of the association didn't entered
the payment in Odoo.

Configuration
=============

- Go to "Settings > General Setttings > Website"

- Check or uncheck 'Waiting Membership' and 'Invoiced Membership'
  checkboxes.

|res_config_settings_form|

.. |res_config_settings_form| image:: https://raw.githubusercontent.com/OCA/vertical-association/18.0/website_membership_non_paid_member/static/description/res_config_settings_form.png

Usage
=====

- Create members with various membership status

|res_partner_list|

- then go to you website, on the ``/members`` page. Now, not only
  invoiced and free are displayed.

|website_membership|
