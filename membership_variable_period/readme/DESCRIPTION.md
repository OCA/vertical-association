The base `membership` module allows to set products that define a fixed
period for a membership. This is good when the quotas are defined
periodically, and when you become a member, you are until the end of
that quota cycle.
Example: memberships from 1st January to December 31st, no matter when
they are subscribed.

But a lot of times, membership quotas express an amount of time that you
gain the membership.
Example: one year of membership since the subscription.

This module allows to make it in Odoo. As now the quota is not attached
to a fixed period, you can also invoice more than one quantity for being
a member for the corresponding number of periods.
Example: subscribe for 2 years in 1 sell, to be a member for the next 2 years.
